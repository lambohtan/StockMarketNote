# AI 辅助投资系统 — 起步调研报告

调研日期：2026-08-28
背景：Fidelity 账户，每月约 $1000，只做美股，目前持有 VOO / QQQ + 若干科技单股

---

## 一、Fidelity 有没有给个人用户的 API？

### 结论：官方没有。但"只读拿数据"有干净的合法路径，"自动下单"没有。

| 路径 | 能做什么 | 成本 | 风险 | 推荐度 |
|---|---|---|---|---|
| **Fidelity 官方零售 API** | — | — | 不存在 | ✗ |
| **SnapTrade** | 只读：持仓、余额、订单、历史交易；OAuth 授权，不交出账号密码 | 免费 Starter 档 5 个账户；付费 $1/用户/月（日频）或 $2（实时） | 低 | ★★★★★ |
| **Fidelity CSV 导出** | Positions / Activity 页面手动下载 | 免费 | 无 | ★★★★（起步够用） |
| **非官方库**（`fidelity-api`、`fidelipy`、Auto-StockTrader，基于 Playwright/Selenium 模拟登录） | 读 + 下单 | 免费 | **违反 Fidelity ToS，可能封号** | ✗ 不建议 |
| **Plaid** | — | — | Fidelity 官方明确表示不使用 Plaid | ✗ |

### 细节

- Fidelity 只对机构客户提供 FIX 连接，零售端没有公开 API，也没有官方宣布的计划。
- **Fidelity Access** 是官方的数据共享通道（OAuth + 数据共享面板，可随时撤销授权），但它只对"已经完成集成的第三方"开放 —— 个人开发者拿不到 key。你只能通过一个已集成的第三方（比如 SnapTrade）间接使用它。
- **SnapTrade 的 Fidelity 集成是只读的，明确不支持下单。** 对你目前的需求（监控 + 分析 + 提醒）刚好够；如果哪天真想让程序自动执行交易，得另外开 Interactive Brokers / Alpaca / Schwab / Tradier 的账户 —— 这几家有真正的零售 API。

### 建议
起步阶段先用 **CSV 导出**（零依赖、零成本，先把流程跑通），确认自己真的会天天看之后，再接 **SnapTrade 免费档**做自动同步。

## 三、你看到的那三个功能，可行性拆解

### 1. 监控账户 + 跟踪基金经理持仓
**技术上完全可行，全部免费或接近免费。**
- 账户涨跌：SnapTrade 只读 API，或每周 CSV 导出。
- 基金经理持仓：SEC EDGAR 的 **13F** 文件，官方免费，`edgartools` 一行代码就能拉。也可以看 Dataroma / WhaleWisdom 的整理页面。

⚠️ **最重要的一个坑：13F 有 45 天滞后。**
基金经理季度结束后最多 45 天才申报，所以你看到的"新买入"可能是 1.5–4.5 个月前的动作，价格早就走完了。而且 13F **只报多头股票仓位**，不含做空、期权对冲、债券、非美股 —— 你看到的是残缺的画面。

**正确用法：把 13F 当"选股池 / 研究线索"，不是"买入信号"。** 看到多个价值型基金同时新建仓某只票 → 值得你自己去研究基本面，而不是跟着买。

### 2. 每日推荐 + 手机推送
**推送这部分很简单**：cron / 定时任务 + Pushover（一次性买断，iOS 体验最好）、Telegram Bot（免费）、或 ntfy（免费、可自建）。

**"推荐买卖 + 建议价格"这部分要非常谨慎。**
2025 年的 FINSABER 研究（arXiv:2505.07078）用 20 年、100+ 只股票做了系统回测，结论是：**之前论文里报告的 LLM 选股优势，在更长周期和更宽标的范围下基本消失**。而且失败模式很典型 —— 牛市里过度保守跑输大盘，熊市里过度激进吃大亏。早期那些"AI 跑赢市场"的结论普遍有幸存者偏差和数据窥探问题。

所以：**别让 AI 当预言家，让它当分析师和纪律执行者。**
它擅长的是：读完 10-K 给你摘要、对比同行估值、把你的规则每天不打折扣地执行一遍、在你想追高时把你自己写的规则甩你脸上。
它不擅长的是：预测下周涨跌、给你一个"建议买入价 $187.5"。

### 3. 持续趋势监控（60 天强势 → 回调 → 重新走高）
**这个反而是最靠谱的一条**，因为它是一个**可以写成明确规则的技术信号**，不需要 LLM 猜。

比如可以量化成：
- 相对强度：60 日涨幅排在你观察池前 20%
- 趋势完好：价格在 50 日均线上方，50 日均线在 200 日均线上方
- 回调幅度：从 60 日高点回撤 8–15%（不是崩了）
- 重新走高：收盘价重新站上 20 日均线，且成交量放大

这样的规则可以**回测**（backtesting.py 几十行代码），可以知道历史胜率和最大回撤，而不是靠感觉。这才是相比"看他们运势好就买点"的真正升级。

> 附注：你提到的 SK 海力士（SK hynix）是韩国上市，美股市场买不到正股，只有流动性很差的 OTC 票（HXSCL）。如果想要类似敞口，得考虑相关的美股/ADR 替代品。

## 五、几句不太好听但重要的话

1. **每月 $1000 全买科技单股，和你的 QQQ 是高度重叠的。** QQQ 前十大持仓就是那批科技巨头。你以为在分散，实际是在加杠杆押同一个赛道。
2. **"看运势好就买"这个模式最大的问题不是选股能力，是没有卖出规则。** 加 AI 不会解决这个，写下规则才会。
3. **交易频率是你最容易控制的变量。** 每月 $1000 的体量，多做 5 次交易的滑点和税负（短期资本利得按普通所得税率）可能就吃掉了你辛苦分析出来的那点 alpha。
4. **建议结构：core-satellite。** 80–90% 核心仓（VOO 为主，自动定投，永不手动干预）+ 10–20% 卫星仓（每月 $100–200，做你的主动想法）。这样一年下来你有 12 个数据点可以复盘自己的选股水平，同时最坏情况下也不会伤到本金主体。AI 系统只服务于那 10–20%。

## 六、建议的分阶段落地路线

### Phase 0 — 先写规则（本周，不写代码）
写一份自己的投资纲领（IPS），一页纸就行，回答：
- 核心/卫星比例是多少？
- 什么条件下买入？什么条件下卖出（止盈/止损/基本面变化）？
- 单只票最大仓位占比？
- 每月最多交易几次？

**没有这份东西，后面所有的代码和 AI 都只是给随机决策加了个科学的外壳。**

### Phase 1 — 把数据拿到手（1–2 周）
- Fidelity CSV 导出 → 存成结构化文件（或直接接 SnapTrade 免费档）
- 建立持仓快照的历史记录，能算出：真实收益率、各持仓相关性、和 VOO/QQQ 的重叠度

### Phase 2 — 装 skill，先当分析助手用（2–4 周）
- 装 `tradermonty/claude-trading-skills` 里那 5 个免 API 的 skill 试水
- 让 Claude 每周做一次组合体检 + 单票基本面 deep dive
- 这阶段**不要**加自动推送，先确认输出对你有价值

### Phase 3 — 加自动化（1–2 个月后）
- `edgartools` 拉 13F，跟踪 3–5 个你认可的基金经理，只生成"观察池"
- 把 Phase 0 的规则写成技术信号扫描脚本，回测验证
- 定时任务 + Pushover/Telegram 每日/每周推送

### Phase 4 — 复盘闭环（持续）
- 每笔交易记录：为什么买、依据什么信号、AI 说了什么、结果如何
- 每季度对比：你的主动选股 vs 同期直接买 VOO
- **如果连续 4 个季度跑输，诚实地把卫星仓比例降下来。** 这是整个系统里最有价值的一环。
